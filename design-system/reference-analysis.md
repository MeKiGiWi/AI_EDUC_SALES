# Reference Analysis — Ethereal AI Light UI

## Summary

The uploaded references show a very specific light AI-infrastructure aesthetic:

- Almost completely white canvas.
- Huge, bold, tightly spaced dark navy typography.
- Thin, pale, scientific linework running through the page.
- Blue translucent “crystal shard” decorative objects with soft glow.
- Sparse enterprise cards with white surfaces, pale blue borders, and gentle depth.
- Technical product storytelling: API call, structured JSON output, multimodal signal fusion, credibility/intelligence score.
- Calm, high-trust feeling: less marketing noise, more precision and emptiness.

The important part is the visual grammar, not the exact brand assets.

## Extracted visual DNA

### 1. Canvas

The whole page breathes. Background is not gray SaaS; it is near-white with occasional ethereal glow.

Use:

- `#FBFCFF` / `#FDFDFB` background.
- Very subtle radial blue glow in corners.
- Huge vertical sections with 120-180px spacing.

Avoid:

- Dark mode as the primary theme.
- Dense backgrounds.
- Heavy gradients.
- Confetti/noisy illustrations.

### 2. Typography

The design is carried by type. Headings are intentionally oversized.

Hero pattern:

- Massive stacked headline.
- Weight 800-900.
- Tight line-height around 0.94.
- Strong negative letter spacing.
- Deep navy/black color.

Eyebrow pattern:

- Uppercase.
- Letter-spaced.
- Muted gray or gray-blue.
- Can feel mono/technical.

Body pattern:

- Large but lightweight.
- Muted gray-blue.
- Generous line-height.

### 3. Decoration

Signature decoration is “scientific + ethereal”:

- Blue crystal shards.
- Orbit/signal lines.
- Spirograph/network shapes.
- Pale labels and score pills.

These decorations should feel original and generated with CSS/SVG. Do not embed reference screenshots or copy the exact crystals.

### 4. Components

Cards and interface panels are large, rounded, and soft. They do not feel like default dashboard cards.

Common values:

- Radius: 28-40px.
- Border: pale blue/gray 1px.
- Background: white / translucent white.
- Shadow: wide and very soft.
- Padding: 32-56px.

### 5. Content rhythm

The page alternates between:

- Hero with abstract visual.
- Proof/logo strip in pale gray.
- Large explanatory headline section.
- Step/problem/solution sections with big text.
- Pricing or API cards.
- API pipeline card.
- Big statement with blue words.
- FAQ rows.
- Minimal footer.

## Best-fit use cases

This preset works especially well for:

- AI infrastructure products.
- API platforms.
- Trust/safety products.
- Sales/revenue intelligence.
- Interview, compliance, hiring, legal, coaching, or behavioral analytics tools.
- Deep-tech B2B SaaS.

It is less suitable for:

- Consumer social apps.
- Playful creator tools.
- E-commerce.
- Banking dashboards that require dense data.
