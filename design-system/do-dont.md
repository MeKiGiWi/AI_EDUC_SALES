# Do / Don't

## Do

- Use near-white backgrounds.
- Let whitespace dominate.
- Make headings enormous.
- Use deep navy text.
- Use blue for selected emphasis.
- Add CSS/SVG crystal and orbit decorations.
- Build original API/pipeline visuals.
- Use pale borders and large rounded corners.
- Keep UI panels sparse.
- Make the product feel like infrastructure.

## Don't

- Do not copy Voicera logo, exact text, exact layouts, or images.
- Do not use the screenshots as assets.
- Do not make the site dark by default.
- Do not use generic SaaS gradients.
- Do not overfill sections with icons.
- Do not make all buttons bright blue.
- Do not use small default headings.
- Do not use hard black text everywhere.
- Do not add random colors.
- Do not make the design feel like a dashboard template.
