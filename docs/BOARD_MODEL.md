# BOARD_MODEL

## Пользовательские поверхности

- сайт / интерфейс для пользователей;
- мобильное приложение / диалог;
- выгрузка отчетов в PDF;
- выгрузка статистики для HR/L&D;
- выгрузка динамики показателей оценки.

## Роли

- ученик;
- руководитель / линейный;
- HR/L&D;
- администратор.

## MVP-модули

### Диалог

- понимание речи / текста / голоса;
- генерация ответов;
- управление диалогом;
- контекст и память.

### Сценарии

- сценарии продаж;
- сценарии поведения персонажей;
- сценарии кейсов.

### Оценка и аналитика

- оценка ответов;
- модель компетенций;
- уровни роли;
- аналитика и отчеты.

### Персонализация

- рекомендации;
- треки развития;
- сложность кейсов по уровню;
- фокус на пробелы.

### Обратная связь

- комментарии ИИ;
- примеры лучших ответов;
- рекомендации.

## База знаний

- продукт;
- навыки продаж;
- сценарии и кейсы;
- обучение;
- оценка;
- обратная связь.

## Панели

- панель ученика;
- панель руководителя;
- панель HR/L&D.

## Системный слой

- профили пользователей;
- история обучения;
- настройки доступа;
- отправка отчетов в зависимости от уровня доступа.
