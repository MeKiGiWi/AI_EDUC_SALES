# Как будет работать edge-часть

Edge-модель будет располагаться рядом с пользовательским интерфейсом:

1. в мобильном приложении;
2. в web UI;
3. в приложении сотрудника офиса.

Она будет получать агрегированные признаки клиента и список доступных офферов, после чего рассчитывать итоговый score для каждого предложения.
После этого система сортирует предложения и возвращает топ-3.

### Метрики

Ок, тогда оставляем только 4 метрики:

1. Precision@3

Показывает, сколько из топ-3 рекомендаций действительно релевантны клиенту.

2. NDCG@3

Показывает, насколько правильно модель расставила офферы внутри топ-3.

Важно не только выбрать подходящие предложения, но и поставить самое релевантное на первое место.

3. CTR simulation

Показывает, как часто клиенты кликают на рекомендации в симуляции.
CTR simulation = количество кликов / количество показов

4. Business value

Показывает условную бизнес-ценность рекомендаций для банка.
Каждому офферу задаем profit_score от 1 до 10.

Пример:

```text
Накопительный счет = 4
Кредитная карта с кешбэком = 7
Потребительский кредит = 8
Ипотека = 10
```

Считаем только офферы, по которым клиент начал заявку:

```text
Business value = сумма profit_score по офферам с application_started = 1
```

Пример:

```text
Клиент начал заявку на кредитную карту: profit_score = 7
Клиент начал заявку на накопительный счет: profit_score = 4

Business value = 7 + 4 = 11
```
