# Copy Tone

## Voice

- confident
- technical
- minimal
- high-trust
- API/infrastructure oriented
- no hype overload

## Sentence patterns

Use short, declarative claims:

- “One API call. One new signal. Better decisions.”
- “Turn conversations into structured intelligence.”
- “Measure the signals your transcript misses.”
- “Built for platforms, not another dashboard.”

## Avoid

- “Revolutionary”
- “Game-changing”
- “10x your business”
- Buzzword-heavy paragraphs
- Consumer-style emotional hype

## Preferred vocabulary

- signal
- intelligence layer
- structured output
- multimodal
- behavioral data
- confidence
- integrity
- intent
- review recommended
- real-time
- API-first
- pipeline
- data layer
- trust workflows
