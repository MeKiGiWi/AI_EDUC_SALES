# Green Sales Academy Landing

Этот репозиторий содержит один актуальный продуктовый артефакт: зелёный лендинг `AI Sales Academy` на `Next.js`.

## Что оставлено

- `app/` и `components/landing/` — рабочий лендинг
- `components/crystal-field.tsx` и `components/orbit-lines.tsx` — декоративная графика
- `design-system/` — зелёный preset, токены, правила и рецепты для дальнейшей генерации
- `codex-prompts/` — короткие промпты только для зелёного направления

## Визуальная рамка

- светлый холст
- спокойный зелёный акцент
- большие заголовки
- много воздуха
- мягкие enterprise-карточки
- акцент на развитии sales-команд, KPI и ИИ-практике

## Команды

```bash
npm run dev
npm run build
npm run typecheck
```

## Как развивать дальше

При любых следующих генерациях ориентируйся на `AGENTS.md` и `design-system/`. В проекте больше не должно быть синих пресетов, альтернативных лендингов или параллельных визуальных систем.
