# Layout Recipes

## Landing page recipe

1. **Navbar**
   - Wordmark left.
   - Product/Solutions/Company nav.
   - Small blue arrow or action icon.
   - Muted CTA right.

2. **Hero**
   - Eyebrow.
   - Huge stacked heading.
   - Muted paragraph.
   - Understated CTA.
   - Right-side or background signal graphic: crystals, orbit lines, score pill.

3. **Trust/proof strip**
   - Pale gray logos or text placeholders.
   - Very low contrast.
   - Enough spacing that it almost fades into background.

4. **Big thesis section**
   - Centered eyebrow.
   - Massive headline, 2-3 lines.
   - Thin orbit line behind.

5. **Problem / solution / delivery section**
   - Numbered pills `01`, `02`, `03`.
   - Large explanatory text blocks.
   - Optional large card/diagram on opposite side.

6. **Pricing or package section**
   - Big faint headline.
   - Toggle pill.
   - 2-3 large cards.
   - Keep top headline and subtext low-contrast.

7. **API section**
   - Left strong headline.
   - Right pipeline card.
   - Thin network diagram behind left copy.
   - Monospace status line below.

8. **Use-case statement**
   - One large centered sentence.
   - Selected industry/use-case words in blue.
   - No extra cards unless necessary.

9. **FAQ**
   - Big rounded rows.
   - Decorative crystals below or behind.

10. **Footer**
   - Decorative strip top.
   - Columns.
   - Minimal brand/social/legal row.

## Product/Solutions page recipe

1. Navbar.
2. Hero with badge pill and split heading: muted words + dark words.
3. Very large blank midsection if there is no strong content.
4. 3-4 capability cards.
5. API/partner CTA.
6. Footer.

## Developer/API page recipe

1. Hero with big claim.
2. API card above the fold.
3. Pipeline diagram.
4. Docs-style endpoint blocks.
5. SDK/REST/WebSocket chips.
6. Use cases.
7. CTA.

## Mobile layout

- Hero heading: `clamp(48px, 16vw, 72px)`.
- Hide large orbit lines that reduce readability.
- Convert pipeline card stages to vertical stack.
- Cards full width.
- Nav collapsed.
- Keep vertical spacing generous, but reduce section padding to 72-96px.
