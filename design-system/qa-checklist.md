# QA Checklist for Codex

Before considering a page done, answer yes/no:

## Style match

- [ ] Is the canvas primarily white/near-white?
- [ ] Is there a lot of vertical whitespace?
- [ ] Is the hero headline massive and tightly spaced?
- [ ] Are headings deep navy, not generic black?
- [ ] Are blue accents restrained and high-impact?
- [ ] Are there original blue crystal/prism or orbit-line decorations?
- [ ] Are cards large, rounded, pale, and soft?
- [ ] Does the page contain a technical API/pipeline/signal motif where relevant?
- [ ] Does it feel like premium AI infrastructure rather than generic SaaS?

## Originality/safety

- [ ] No copied Voicera text.
- [ ] No Voicera logo.
- [ ] No copied screenshots/assets.
- [ ] Layout is inspired by the reference but not a pixel clone.
- [ ] Product copy uses the user’s own content.

## Implementation

- [ ] Mobile layout is usable.
- [ ] Important text has enough contrast.
- [ ] Decorative elements do not block clicks/readability.
- [ ] Build/lint passes if scripts exist.
- [ ] Components are reusable.
